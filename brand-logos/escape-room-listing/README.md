# Escape room Etsy listing photos (Barry, 28 Nov 2026)

- `scene-blank.png`: the reusable scene (mahogany table, fountain pen, magnifying glass, crowbar, blank cream booklet),
  made in ChatGPT with "prompt 1". Every escape room's main photo uses this same scene.
- `aunt-doris-main.png`: Escape From Aunt Doris, made with "prompt 2" (the scene + the booklet's cover as one flat PNG).

Prompt 2, for each new room (upload scene-blank.png and the room's cover PNG, page 1 of its booklet):

> Place the second image onto the blank cover of the booklet in the first image, as if it were printed on that cover.
> Keep the cover artwork exactly as it is, with every word unchanged and nothing redrawn, but give it the same warm
> lighting, shadow and matte paper texture as the booklet, so it looks printed, not pasted on. Don't change anything
> else in the photo.

Check the small print afterwards; rerun if any wording changed.

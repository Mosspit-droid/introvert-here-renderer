# Workshop brief: Personalised (new spin-off range)

## Background
Introvert Here (Mosspit Studios) is an Etsy shop selling print-on-demand clothing printed with short deadpan jokes ("gags") about introverts. Printify makes and ships every order; designs are built in Canva; the approvals app and Make automations run everything from a spreadsheet called Core.

- **Main range:** Introvert Here (code IH).
- **Spin-off ranges, each separate with its own code:** SHHH. (SH), Per Contract (PC), Off The Shelf (OS).
- **Gag codes:** range code plus number, e.g. IH-00123.
- **Release schedule:** each gag comes on 4 garments (T-shirt, long-sleeve, sweatshirt, hoodie) and releases on a weekly schedule planned years ahead.
- **Prices:** T-shirt £26.99, long-sleeve £29.99, sweatshirt £39.99, hoodie £49.99, with free postage built in.
- **How orders work today:** Etsy orders pass to Printify automatically, and the same design is printed for every buyer.
- Setting up a spin-off is about a week's work including writing the gags; PC and OS took roughly that.

## The idea
A spin-off range where the buyer adds their own words to a design, e.g. a name or a short line slotted into a joke. It was ruled out early in the project as too much work. Most of the hurdles have probably gone since:
- the app can already make print files from Canva by filling in text (autofill);
- the shop website already sends orders to Printify by itself, through the API;
- Etsy listings have a built-in personalisation box.

## Agreed so far
- **Its own range** with its own code, treated separately like SH, PC and OS.
- Everything else is open.

## To workshop
1. **Identity:** the range name, its two-letter code and number format, and how it relates to the main brand.
2. **What gets personalised:** a name, a word in a fill-in-the-blank joke, a date? One template per gag, or a few flexible templates?
3. **Limits:** maximum length, allowed characters, and how long text is fitted (shrink, wrap, refuse).
4. **What gets refused:** swearing, other people's trademarks, offensive text. Is it checked automatically, by Barry, or both?
5. **Proof:** does the buyer see a preview before buying, and does Barry check each print before it goes to Printify?
6. **Order flow:** catch the Etsy order, read the personalisation, make that buyer's print file in Canva, create a custom Printify order, and stop Printify's normal automatic order for that listing. What happens if a step fails?
7. **Garments and price:** which garments, and is there a personalisation surcharge?
8. **Returns:** personalised items usually can't be returned. How does that fit Etsy's rules and the shop's policy?
9. **Listings and mockups:** listing photos showing example text, and the Etsy section, title and tags.
10. **Effort and cost:** Make credits per order, Canva export limits, and Barry's time per order.
